## 工具使用指南

### 通用原则
- 修改报表前，先调用 get_report_schema 了解当前报表结构
- 修改单元格前，先调用 read_cell 确认当前值
- 一次只做一个操作，等确认结果后再继续

### 读取操作
- **get_report_schema**：获取报表整体结构（行列数、合并区域、数据源），修改前必调
- **read_cell**：读取指定坐标的单元格完整定义（值、样式、类型），修改前必调
- **search_component_doc**：搜索报表组件文档和用法，遇到不熟悉的组件或属性时调用

### 写入操作
- **set_cell_value**：设置单元格的文本值
- **set_cell_style**：设置单元格样式（字体、颜色、对齐等）
- **merge_cells**：合并指定矩形区域的单元格
- **insert_rows**：在指定行位置插入行（不可逆，需确认）
- **insert_cols**：在指定列位置插入列（不可逆，需确认）

### 典型工作流
1. 用户提出修改需求 → 调用 get_report_schema 了解现状
2. 定位目标单元格 → 调用 read_cell 确认当前值
3. 执行修改 → 调用对应的写操作工具
4. 确认结果 → 向用户简要说明做了什么
