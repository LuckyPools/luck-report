# 函数说明

## 一、概述

函数是 Luck-Report 内置的可调用计算单元，可在单元格表达式、条件属性、图片来源、二维码数据源等位置使用。函数语法格式为 `函数名(表达式, 表达式, ...)`，参数可以是单元格引用、数据集表达式、字面量或其他函数的返回值。

Luck-Report 内置函数共 5 大类 40 个，分类如下：

| 分类 | 函数数量 | 说明 |
|------|---------|------|
| 常用函数 | 14 | 统计、排序、取参、格式化等报表高频操作 |
| 日期函数 | 5 | 获取当前日期、年、月、日、星期 |
| 数学函数 | 18 | 绝对值、四舍五入、三角函数、统计量等 |
| 字符串函数 | 8 | 字符串查找、截取、替换、大小写转换等 |
| 分页函数 | 8 | 当前页统计、页码输出，多用于重复表头/表尾行 |

## 二、详情

### 1、常用函数

| 函数名 | 参数 | 说明 | 案例 | 约束 |
|--------|------|------|------|------|
| count | `(表达式1, 表达式2, ...)` | 统计给定表达式计算后的对象数量 | `count(C1)` 统计 C1 单元格数量；`count(C1{age>20},C2)` 统计 age>20 的 C1 和 C2 数量 | 参数为单元格引用，可带条件 `{条件}` |
| sum | `(表达式1, 表达式2, ...)` | 对给定表达式计算后的值累加 | `sum(C1)` 累加所有 C1 值；`sum(C1{age>20})` 累加 age>20 的 C1 值 | 各表达式计算值必须为数字 |
| avg | `(表达式1, 表达式2, ...)` | 对给定表达式计算后的值求平均值 | `avg(C1)` 求 C1 平均值；`avg(C1,C2)` 求 C1 和 C2 平均值 | 各表达式计算值必须为数字；除不尽保留 8 位小数 |
| max | `(表达式1, 表达式2, ...)` | 对给定表达式计算后的值取最大值 | `max(C1)` 取 C1 最大值；`max(C1{age>20},C2)` 取满足条件的最大值 | 各表达式计算值必须为数字 |
| min | `(表达式1, 表达式2, ...)` | 对给定表达式计算后的值取最小值 | `min(C1)` 取 C1 最小值；`min(C1,C2)` 取 C1 和 C2 最小值 | 各表达式计算值必须为数字 |
| row | `()` | 取当前单元格所在行的行号 | `row()` 返回当前行号 | 无参数 |
| column | `()` | 取当前单元格所在列的列号 | `column()` 返回当前列号 | 无参数 |
| dataRow | `()` | 取当前单元格所在数据行的行号（从1开始） | `dataRow()` 返回数据行序号 | 无参数；自动计算从左父格到当前行的有效数据行序号 |
| order | `(表达式, 布尔值)` | 对表达式结果排序，true 正序，false 倒序 | `order(C1,false)` 对 C1 值倒排序；`order(C1{age>18},true)` 对满足条件的 C1 正排序 | 第二个参数必须为布尔值 |
| list | `(表达式1, 表达式2, ...)` | 取表达式中定义的所有数据，以集合形式返回 | `list(C1)` 返回所有 C1 值的集合；`list(C1,C2{age>20})` 返回 C1 和满足条件的 C2 集合 | — |
| param | `(参数名)` | 获取外部传入的参数值 | `param("deptId")` 获取名为 deptId 的参数；`param(C1)` 以 C1 值作为参数名获取参数 | 参数名为字符串或单元格引用 |
| emptyparam | `(参数名)` | 判断外部参数是否为 null 或空字符串 | `emptyparam("name")==false` 判断 name 参数非空 | 返回布尔值；多用于 SQL 数据集条件判断 |
| formatdate | `(日期对象[, 格式模式])` | 格式化日期对象为字符串 | `formatdate(C1)` 按 yyyy-MM-dd HH:mm:ss 格式化；`formatdate(C1,"yyyyMMdd")` 按指定格式格式化 | 第一个参数必须为日期类型；第二个参数可选，默认 yyyy-MM-dd HH:mm:ss |
| formatnumber | `(数字对象[, 格式模式])` | 格式化数字为字符串 | `formatnumber(C1)` 按 # 格式化；`formatnumber(C1,"#,###.00")` 按千分位两位小数格式化 | 第一个参数必须可转换为数字；第二个参数可选，默认 # |
| get | `(集合对象[, 位置[, 属性名]])` | 获取集合中指定位置的对象或属性值 | `get(ds1.select(employee_name))` 取第1个；`get(ds1.select(employee_name),2)` 取第2个；`get(ds1.select(employee_name),2,"deptId")` 取第2个的 deptId 属性；`get(A3,4)` 取第4个 A3 值 | 位置参数从1开始，未指定默认取第1个 |

### 2、日期函数

| 函数名 | 参数 | 说明 | 案例 | 约束 |
|--------|------|------|------|------|
| date | `([格式模式])` | 输出当前日期 | `date()` 输出 yyyy-MM-dd HH:mm:ss 格式日期；`date('yyyy年MM月dd日')` 按指定格式输出 | 参数可选，默认 yyyy-MM-dd HH:mm:ss |
| day | `()` | 输出当前月份中的天 | `day()` 可能输出 15 | 无参数 |
| month | `()` | 输出当前月份 | `month()` 可能输出 8 | 无参数 |
| week | `()` | 输出当前星期几 | `week()` 可能输出 "星期三" | 无参数 |
| year | `()` | 输出当前年份 | `year()` 输出 2026 | 无参数 |

### 3、数学函数

| 函数名 | 参数 | 说明 | 案例 | 约束 |
|--------|------|------|------|------|
| abs | `(表达式)` | 求绝对值 | `abs(-233)` 返回 233；`abs(C1)` 返回 C1 值的绝对值 | 参数值必须为数字 |
| ceil | `(表达式)` | 向上取整（舍弃小数） | `ceil(32.32)` 返回 32；`ceil(C1)` 取 C1 值向上取整 | 参数值必须为数字 |
| floor | `(表达式)` | 四舍五入取整 | `floor(32.52)` 返回 33；`floor(C1)` 取 C1 值四舍五入 | 参数值必须为数字 |
| round | `(表达式[, 小数位数])` | 四舍五入，可指定保留小数位数 | `round(32.12)` 返回 32；`round(32.123,2)` 返回 32.12；`round(C1,2)` 保留两位小数 | 第二个参数可选，未指定则不保留小数 |
| chn | `(表达式)` | 将数字转为中文大写 | `chn(213)` 返回 "贰佰壹拾叁"；`chn(C1)` 将 C1 值转中文 | 参数值必须为数字；小数最多支持两位，超出四舍五入 |
| rmb | `(表达式)` | 将数字转为中文大写人民币金额 | `rmb(213)` 返回 "贰佰壹拾叁元整"；`rmb(200.12)` 返回 "贰佰元壹角贰分" | 参数值必须为数字；小数最多支持两位，超出四舍五入 |
| cos | `(表达式)` | 求余弦值 | `cos(213)` 返回 0.809；`cos(C1)` 取 C1 值的余弦 | 参数值必须为数字 |
| sin | `(表达式)` | 求正弦值 | `sin(213)` 返回 -0.588；`sin(C1)` 取 C1 值的正弦 | 参数值必须为数字 |
| tan | `(表达式)` | 求正切值 | `tan(213)` 返回 -0.727；`tan(C1)` 取 C1 值的正切 | 参数值必须为数字 |
| exp | `(表达式)` | 返回 e 的参数次方 | `exp(2)` 返回 7.389；`exp(C1)` 取 C1 值的 e 次方 | 参数值必须为数字 |
| log | `(表达式)` | 求自然对数 | `log(213)` 返回 5.361；`log(C1)` 取 C1 值的自然对数 | 参数值必须为数字 |
| log10 | `(表达式)` | 求以10为底的对数 | `log10(213)` 返回 2.328；`log10(C1)` 取 C1 值的以10为底对数 | 参数值必须为数字 |
| pow | `(表达式1, 表达式2)` | 返回第一个参数的第二个参数次方 | `pow(3,2)` 返回 9；`pow(C1,3)` 取 C1 值的3次方 | 两个参数都必须为数字 |
| sqrt | `(表达式)` | 求平方根 | `sqrt(2)` 返回 1.414；`sqrt(C1)` 取 C1 值的平方根 | 参数值必须为数字 |
| random | `([表达式])` | 生成随机数 | `random()` 生成 0~1 随机数；`random(10)` 生成 1~10 随机数 | 参数可选；有参数时以参数为种子 |
| median | `(表达式1, 表达式2, ...)` | 求中位数 | `median(12,42,31)` 返回 31；`median(C1)` 取 C1 值的中位数 | 参数值必须为数字 |
| mode | `(表达式1, 表达式2, ...)` | 求众数 | `mode(12,42,3,12)` 返回 12；`mode(C1)` 取 C1 值的众数 | 参数值必须为数字 |
| vara | `(表达式1, 表达式2, ...)` | 求方差 | `vara(12,42,3,12)` 返回 209.25；`vara(C1)` 取 C1 值的方差 | 参数值必须为数字 |
| stdevp | `(表达式1, 表达式2, ...)` | 求标准差 | `stdevp(12,42,3,12)` 返回 14.754；`stdevp(C1)` 取 C1 值的标准差 | 参数值必须为数字 |

| 函数名 | 参数 | 说明 | 案例 | 约束 |
|--------|------|------|------|------|
| indexof | `(目标字符串, 查找字符串[, 起始位置])` | 返回查找字符串在目标字符串中的位置 | `indexof('中华人民共和国','共和')` 返回位置；`indexof(C1,"人民",2)` 从第2位开始查找 | 第三个参数可选，必须 ≥ 0 |
| length | `(表达式)` | 求字符串长度 | `length("中华人民共和国")` 返回 7；`length(C1)` 取 C1 值的长度 | 必须有一个参数 |
| lower | `(表达式)` | 将英文转为小写 | `lower("Super man")` 返回 "super man"；`lower(C1)` 将 C1 值转小写 | 必须有一个参数 |
| upper | `(表达式)` | 将英文转为大写 | `upper("Super man")` 返回 "SUPER MAN"；`upper(C1)` 将 C1 值转大写 | 必须有一个参数 |
| replace | `(目标字符串, 被替换字符串, 替换字符串)` | 替换字符串 | `replace("他是一个好人","他","她")` 返回 "她是一个好人" | 必须有三个参数 |
| substring | `(目标字符串, 起始位置[, 结束位置])` | 截取子字符串 | `substring("他是一个好人",2)` 返回 "一个好人"；`substring("他是一个好人",2,4)` 返回 "一个" | 第三个参数可选 |

### 5、分页函数

分页函数在分页预览时计算，多用于行类型为"重复表头行"或"重复表尾行"的单元格中。

| 函数名 | 参数 | 说明 | 案例 | 约束 |
|--------|------|------|------|------|
| pcount | `(表达式1, 表达式2, ...)` | 统计当前页中表达式的数目 | `pcount(C1)` 统计当前页 C1 数量；`pcount(C1,D2{D2>10000})` 统计当前页满足条件的数量 | 仅统计当前页 |
| psum | `(表达式1, 表达式2, ...)` | 将当前页中表达式值累加 | `psum(C1)` 累加当前页 C1 值；`psum(C1,D2{D2<10000})` 累加当前页满足条件的值 | 仅针对当前页 |
| pmax | `(表达式1, 表达式2, ...)` | 取当前页中表达式值的最大值 | `pmax(C1)` 取当前页 C1 最大值 | 仅针对当前页 |
| pmin | `(表达式1, 表达式2, ...)` | 取当前页中表达式值的最小值 | `pmin(C1)` 取当前页 C1 最小值 | 仅针对当前页 |
| pavg | `(表达式1, 表达式2, ...)` | 取当前页中表达式值的平均值 | `pavg(C1)` 取当前页 C1 平均值 | 仅针对当前页 |
| prows | `()` | 返回当前页的数据行数 | `prows()` 返回当前页行数 | 无参数 |
| page | `()` | 输出当前页码 | `page()` 返回当前页码 | 无参数 |
| pages | `()` | 输出报表总页数 | `pages()` 返回总页数 | 无参数；仅能在页眉页脚中使用 |

## 三、函数通用约束

| 约束编号 | 约束说明 |
|---------|---------|
| F-01 | 函数名大小写不敏感，`count` 和 `Count` 等效 |
| F-02 | 单元格引用参数（如 C1）是相对当前单元格计算的，遵循同行/同列/共同父格取值原则 |
| F-03 | 单元格引用可带条件，格式为 `单元格名{条件}`，如 `C1{age>20}` |
| F-04 | 多个单元格引用参数时，函数会将所有引用的值合并计算 |
| F-05 | sum/avg/max/min 等聚合函数要求参数值为数字类型，否则报错 |
| F-06 | 分页函数只在分页预览时生效，非分页模式下不计算 |
| F-07 | pages 函数仅能在页眉页脚中使用 |
| F-08 | json 函数要求 JSON 字符串为标准格式，key 必须用双引号包裹 |
