# 报表说明

## 一、概述

报表（Report）是 Luck-Report 的核心数据结构，用于定义一份完整的报表模板。报表由单元格网格、数据源、纸张设置、页眉页脚、查询表单等元素组成，每个单元格可配置不同类型的数据值，通过展开方向和父子格关系实现动态数据填充。

---

## 二、报表构成要素

| 要素 | 字段名 | 类型 | 说明                                          |
|------|--------|------|---------------------------------------------|
| 纸张设置 | paper | 对象 | 定义报表页面尺寸、边距、方向、分页模式等             |
| 页眉 | header | 对象 | 报表每页顶部显示的内容，支持左/中/右三区域及表达式                  |
| 页脚 | footer | 对象 | 报表每页底部显示的内容，支持左/中/右三区域及表达式                  |
| 查询表单 | searchForm | 对象 | 预览时渲染为查询条件表单，用于数据集参数筛选          |
| 数据源列表 | datasources | 数组 | 报表引用的数据源集合，每个数据源下包含数据集，数据集包含字段 |
| 行定义列表 | rows | 数组 | 报表所有行的定义，包含行号、行高、行类型（Band）        |
| 列定义列表 | columns | 数组 | 报表所有列的定义，包含列号、列宽、是否隐藏             |
| 单元格列表 | cells | 数组 | 报表所有单元格的定义，是报表的核心数据         |

---

## 三、单元格核心概念

### 1、单元格网格

报表以二维网格形式组织，每个单元格通过 `rowNumber`（行号）和 `columnNumber`（列号）定位，单元格名称格式为列字母+行号，如 `A1`、`B3`。单元格支持合并（`rowSpan`/`colSpan`）。

### 2、单元格值类型（ValueType）

每个单元格的 `value.type` 决定了该单元格的数据来源和渲染方式：

| 枚举值 | 说明 |
|--------|------|
| simple | 普通文本，直接显示静态文本内容 |
| expression | 表达式，通过表达式动态计算值 |
| dataset | 数据集，绑定数据集字段，根据聚合方式取值 |
| image | 图片，显示指定图片 |
| chart | 图表，在单元格中渲染 ECharts 图表 |
| slash | 斜表头，用于绘制交叉表头 |
| zxing | 二维码/条码，根据 category 区分 qrcode 或 barcode |

### 3、单元格展开方向（Expand）

当单元格绑定数据集字段且数据有多条时，通过展开方向控制单元格如何扩展：

| 枚举值 | 说明 |
|--------|------|
| Down | 向下展开，数据多行时单元格向下复制扩展 |
| Right | 向右展开，数据多列时单元格向右复制扩展 |
| None | 不展开，仅显示第一条数据 |

### 4、父子格关系

单元格之间存在依赖关系，通过左父格（`leftParentCellName`）和上父格（`topParentCellName`）定义。父格展开时会带动子格一起展开，这是报表动态渲染的核心机制，详见《父子格关系说明》。

### 5、单元格通用属性

单元格通用属性是所有值类型单元格共享的基础配置，定义在 `cell` 上，不随值类型变化。包括父子格关系、展开方向、单元格样式（cellStyle）、链接配置、渲染器、填充空白行、条件属性等。通用属性控制单元格"如何展示"和"如何与数据联动"，与值类型控制"展示什么内容"互补：父子格+展开方向决定数据集单元格展开时如何复制定位，cellStyle 控制字体/颜色/对齐/边框等视觉表现，链接配置提供超链接跳转能力，填充空白行控制数据不足时补行。值类型（`value.type`）决定属性面板显示哪个值编辑器，而通用属性面板在所有值类型下都可见，两者共同构成单元格完整定义——值类型管"数据来源"，通用属性管"展示与行为"。

### 6、单元格条件属性

条件属性定义在 `cell.conditionPropertyItems` 中，是条件分组列表，每个分组包含一组条件（conditions）和满足条件后生效的效果（样式、新值、链接、行高列宽、分页等）。渲染时按分组顺序依次判断，多个分组效果可叠加。条件属性用于根据数据值动态改变单元格外观和行为，如数据高亮（销售额超阈值时背景变红）、条件替换值（状态码转文字）、条件分页、条件链接等。条件属性与通用属性的关系是"动态覆盖层"：通用属性定义默认样式和行为，条件属性在满足条件时覆盖默认值，未覆盖的属性保持通用属性设置。条件样式额外提供 Scope 作用范围（cell/row/column），可将效果扩展到整行或整列。条件属性在数据集值编辑器和通用属性面板中均可配置，两处修改同步。

### 7、不同值类型单元格的数据关联

报表中不同值类型的单元格通过以下机制产生数据关联：父子格关系使不同类型单元格在空间上对齐（如数据集单元格 A1 向下展开列出部门，文本单元格 B1 以 A1 为上父格则随行展开）；表达式引用使 expression 类型单元格可引用其他单元格值建立计算依赖；数据集共享使多个 dataset 类型单元格绑定同一数据集不同字段，通过父子格自动对齐同一数据行；条件属性跨类型生效，任何值类型单元格都可配置条件属性且条件中可引用任意单元格值。典型关联模式：数据集+文本（展开提供数据行，文本随行显示标题）、数据集+表达式（表达式引用数据集单元格做汇总/环比/同比计算）、数据集+图表（绑定同一数据集可视化展示）、数据集+条件属性（根据字段值动态改变样式）。

## 四、表达式与函数

表达式是 Luck-Report 中用于动态计算值的语法结构，编写在 expression 类型单元格的 `value.value` 字段中，也可用于条件属性、图片来源、二维码数据源等位置。表达式由基本数据类型、运算符、条件判断、单元格引用、数据集表达式和函数调用组合而成，是报表实现动态计算的核心能力：引用其他单元格值进行计算、通过 if/case/三元表达式条件输出、使用数据集表达式（如 `ds1.sum(salary)`）聚合统计、通过 `param()` 获取查询参数、通过函数格式化输出。表达式与 simple（静态文本）、dataset（数据集绑定）并列作为单元格值来源，可通过单元格引用与 dataset 类型单元格产生数据依赖，条件属性的条件判断中也使用表达式语法。函数是表达式可调用的内置计算单元，共 5 大类 40 个（常用函数、日期函数、数学函数、字符串函数、分页函数），详见《函数说明》。
