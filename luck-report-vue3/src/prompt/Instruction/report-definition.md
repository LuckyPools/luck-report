# 报表说明

## 一、概念说明

报表（Report）是 Luck-Report 的核心数据结构，用于定义一份完整的报表模板。报表由单元格网格、数据源、纸张设置、页眉页脚、查询表单等元素组成，每个单元格可配置不同类型的数据值，通过展开方向和父子格关系实现动态数据填充。

## 二、报表构成要素

| 要素 | 字段名 | 说明 |
|------|--------|------|
| 纸张设置 | paper | 页面尺寸、边距、方向、分页模式 |
| 页眉 | header | 每页顶部内容，支持左/中/右三区域 |
| 页脚 | footer | 每页底部内容，支持左/中/右三区域 |
| 查询表单 | searchForm | 预览时的查询条件表单 |
| 数据源列表 | datasources | 数据源集合，每个数据源下包含数据集 |
| 行定义列表 | rows | 所有行的定义，包含行号、行高、行类型 |
| 列定义列表 | columns | 所有列的定义，包含列号、列宽、是否隐藏 |
| 单元格列表 | cells | 所有单元格的定义，是报表核心数据 |

## 三、单元格核心概念

### (一) 单元格值类型（ValueType）

| 枚举值 | 说明 |
|--------|------|
| simple | 普通文本，直接显示静态文本 |
| expression | 表达式，动态计算值 |
| dataset | 数据集，绑定数据集字段 |
| image | 图片，显示指定图片 |
| chart | 图表，渲染可视化图表 |
| slash | 斜表头，绘制交叉表头 |
| zxing | 二维码/条码 |

### (二) 单元格展开方向（Expand）

| 枚举值 | 说明 |
|--------|------|
| Down | 向下展开，数据多行时向下复制 |
| Right | 向右展开，数据多列时向右复制 |
| None | 不展开，仅显示第一条数据 |

### (三) 父子格关系

单元格之间通过左父格（`leftParentCellName`）和上父格（`topParentCellName`）定义依赖关系。父格展开时会带动子格一起展开，这是报表动态渲染的核心机制。详见《父子格关系说明》。

## 四、数据约束

数据约束由 data-schemas.ts 自动校验。主要约束：
- 单元格 rowNumber/columnNumber 必填
- value.type 必须是有效枚举值
- expand 必须是 None/Down/Right
- 数据集类型单元格必须包含 datasetName、aggregate、property
