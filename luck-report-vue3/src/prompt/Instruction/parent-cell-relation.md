# 父子格关系说明

## 一、概述

父子格关系是报表计算模型的核心机制，定义了单元格之间的依赖与联动关系。每个单元格可设置**左父格**（`leftParentCellName`）和**上父格**（`topParentCellName`），父格展开时会带动子格一起展开，从而实现分组汇总、嵌套数据等复杂报表布局。

---

## 二、父格类型

### (一) 左父格（leftParentCellName）

左父格是指当前单元格**左侧与其位于同一行**的父单元格。当左父格向下展开时，当前单元格会跟随左父格一起向下复制扩展。

- 字段：`cell.leftParentCellName`
- 值类型：String
- 值范围：单元格名称（如 `"A1"`、`"B2"`）或 `"root"`（表示无左父格）

### (二) 上父格（topParentCellName）

上父格是指当前单元格**上方与其位于同一列**的父单元格。当上父格向下展开时，当前单元格会跟随上父格一起向下复制扩展。

- 字段：`cell.topParentCellName`
- 值类型：String
- 值范围：单元格名称（如 `"A1"`、`"B2"`）或 `"root"`（表示无上父格）

---

## 三、默认父格规则

未手动配置父格时，系统按以下规则自动推导：

| 场景 | 左父格默认值 | 上父格默认值 |
|------|-------------|-------------|
| 位于第一列的单元格 | `"root"`（无左父格） | 最近上方同列单元格 |
| 位于第一行的单元格 | 最近左侧同行单元格 | `"root"`（无上父格） |
| 位于第一行第一列的单元格 | `"root"` | `"root"` |
| 其他位置单元格 | 最近左侧同行单元格 | 最近上方同列单元格 |

> 前端设计器中，父格配置支持 `default`（默认）和 `custom`（自定义）两种模式。选择 `default` 时按上述规则自动推导，选择 `custom` 时可手动指定父格单元格名称及行号。

---

## 四、父格展开规则

1. **父格展开带动子格**：父格展开时会带动其所有子格一起展开
2. **向下展开传递**：父格向下展开时，带其下所有子格及子格的子格一起向下展开
3. **同数据集数据受限**：如果子格绑定的数据集与父格属于同一个，则子格中的数据将受父格限制（即子格只显示父格当前行对应的数据子集）
4. **子格展开继续传递**：子格绑定的数据集字段在展开时，同样会带动其下子格一起展开
5. **同行列父格拉大**：当前子格的父格如与子格处于同一行或列，则会将父格拉大

---

## 五、配置方式

在设计器中选中单元格后，属性面板的"父单元格"区域可配置左父格和上父格：

| 配置项 | 说明 |
|--------|------|
| 左父格类型 | `default`（默认推导）/ `custom`（自定义） |
| 左父格列名 | 选择列字母，如 A、B、C |
| 左父格行号 | 选择行号，如 1、2、3 |
| 上父格类型 | `default`（默认推导）/ `custom`（自定义） |
| 上父格列名 | 选择列字母 |
| 上父格行号 | 选择行号 |

当类型选择 `custom` 且列名选择 `root` 时，表示该方向无父格。

---

## 六、应用场景

利用父子格展开迭代的特性，可以实现以下报表样式：

- **分组汇总报表**：父格按分组字段展开，子格显示明细数据
- **多层级数据展示**：多层嵌套的父子格关系实现层级展开
- **动态行列扩展**：向右展开实现动态列，向下展开实现动态行
- **交叉报表**：左父格和上父格配合实现交叉维度展示
