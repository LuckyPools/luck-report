# 普通文本单元格说明

## 一、概念说明

普通文本单元格是报表中最基础的单元格类型，用于显示静态文本内容。单元格的 `value.type` 为 `"simple"` 时即为普通文本单元格，`value.value` 存储要显示的文本字符串。

## 二、关键规则

1. **不依赖数据集**：直接显示静态文本，不做任何计算或数据填充。
2. **通常不展开**：`expand` 通常设为 `"None"`。

## 三、数据约束

数据约束由 data-schemas.ts 自动校验。主要约束：
- value.type 固定为 `"simple"`
- value.value 为文本字符串，任意内容
- expand 通常为 `"None"`
