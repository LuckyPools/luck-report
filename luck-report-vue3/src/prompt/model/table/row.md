# 表格行说明

## 一、概念说明

表格行定义用于描述报表中每一行的结构属性，包括行号、行高和行类型（Band）。行类型决定了该行在报表分页输出时的显示位置。

## 二、行类型分页行为

| 类型 | 说明 |
|------|------|
| title | 标题行，仅在第一页最前端显示 |
| headerrepeat | 重复表头行，在每一页顶部显示 |
| footerrepeat | 重复表尾行，在每一页底部显示 |
| summary | 总结行，仅在最后一页最下端显示 |
| null | 普通行，无特殊分页行为 |

## 三、关键规则

1. **rowNumber 从 0 开始**：行索引从 0 开始计数。
2. **行类型影响分页**：设置 Band 类型后，该行会在特定分页位置显示。
3. **操作流程由工作流控制**：读取、修改、插入、删除行的操作由工作流自动控制。

## 四、数据约束

数据约束由 data-schemas.ts 自动校验。主要约束：
- rowNumber 从 0 开始
- band 必须是 headerrepeat/footerrepeat/title/summary 或 null
- height 最小值为 0，单位为像素
