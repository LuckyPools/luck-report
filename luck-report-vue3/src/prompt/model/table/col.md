# 表格列说明

## 一、概念说明
表格列定义用于描述报表中每一列的结构属性，包括列号、列宽和隐藏状态。列头区域以字母标签（A、B、C...）标识列位置。

## 二、关键规则
1. **columnNumber 从 1 开始**：列号从 1 开始，按顺序递增，不可跳号。
2. **列号必须唯一**：插入或删除列时后续列号自动调整。
3. **操作流程由工作流控制**：读取、修改、插入、删除列的操作由工作流自动控制。

## 三、数据约束
数据约束由 data-schemas.ts 自动校验。主要约束：
- columnNumber 从 1 开始，按顺序递增
- width 最小值为 0，单位为像素
- hide 为 true（隐藏）或 false（显示）
