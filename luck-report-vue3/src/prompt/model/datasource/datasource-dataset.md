# 数据源与数据集说明

## 一、概念说明
**数据源**是报表数据的来源，每个数据源下可包含多个数据集。
数据集定义了具体的数据查询逻辑（SQL 或 Spring Bean 方法），报表渲染时后台根据数据集查询数据再填充到单元格中。
数据源和数据集是两个不同的概念，数据集归属于数据源，数据集就是从数据源中提取的数据集合

## 二、关键规则
1. **禁止创建 jdbc/spring 类型数据源**，这两种数据源必须由用户手动添加。助手只能创建 buildin 类型数据源。
2. **buildin 数据源名称必须来自 load_buildin_datasources 返回列表**，禁止凭空编造名称。
3. **数据集 fields 字段必须由 build_fields 工具解析生成**，禁止自行编造。
4. **SQL 数据集必须通过 preview_data 和 build_fields 验证**，验证通过后才能写入。
5. **数据集 sql 支持表达式**：表达式用 `${...}` 包裹，用于与普通 SQL 文本区分。有计算需求时参照 EXPRESSION 表达式文档。

## 三、操作流程
操作流程由工作流自动控制，数据校验由工具自动执行。助手只需按工作流步骤执行即可。

## 四、数据约束
数据约束由 data-schemas.ts 自动校验，校验失败会返回错误信息。主要约束：
- 数据源 name 不能为空，报表内唯一
- 数据源 type 必须是 jdbc/spring/buildin 之一
- 数据集 name 不能为空，数据源内唯一
- 数据集 fields 数组不能为空
- 参数 type 必须是 String/Integer/Float/Boolean/Date/List 之一
