# 表达式说明

## 一、概述

表达式是 Luck-Report 中用于动态计算值的语法结构，可在单元格值（类型为 expression）、条件属性、图片来源、二维码数据源等位置编写。表达式由基本数据类型、运算符、条件判断、单元格引用、数据集表达式和函数调用组合而成。

表达式核心能力分为 6 类：

| 分类 | 说明 |
|------|------|
| 基本数据类型 | 数字、字符串、布尔值 |
| 算术运算符 | +、-、*、/、% |
| 条件判断 | 三元表达式、if 判断、case 判断 |
| 单元格引用 | 直接引用、坐标引用、引用所有、取当前值 |
| 数据集表达式 | 数据集名称.聚合方式(字段名[条件,排序方式]) |
| 函数调用 | 内置函数，详见函数说明 |

## 二、详情

### (一) 基本数据类型与运算符

#### 1. 基本数据类型

| 类型 | 描述 | 案例 |
|------|------|------|
| 数字 | 整数或小数 | `1`、`123`、`0.121331` |
| 字符串 | 用单引号或双引号包裹 | `"Luck-Report"`、`'Luck-Report教程'` |
| 布尔值 | true 或 false | `true`、`false` |

#### 2. 算术运算符

| 操作符 | 描述 | 案例 |
|--------|------|------|
| + | 求和或连接字符串 | `21+31` 结果 52；`"值："+331` 结果 "值：331" |
| - | 求差 | `21-31` 结果 -10 |
| * | 求积 | `3*6` 结果 18 |
| / | 求商，除不尽保留8位小数 | `6/3` 结果 2 |
| % | 求余 | `5%3` 结果 2；`6%2` 结果 0 |

#### 3. 比较运算符

| 操作符 | 描述 | 案例 |
|--------|------|------|
| > | 大于 | `A1>1000` |
| < | 小于 | `A1<20000` |
| >= | 大于等于 | `A1>=100` |
| <= | 小于等于 | `A1<=1000` |
| == | 等于 | `A1==100` |
| != | 不等于 | `A1!=0` |

#### 4. 逻辑运算符

| 操作符 | 描述 | 案例 |
|--------|------|------|
| and | 逻辑与，多个条件同时满足 | `A1>1000 and A1<20000` |
| or | 逻辑或，满足任一条件 | `A1>1000 or A1<100` |

### 2、条件判断表达式

#### 1. 三元表达式

**语法**：`条件 ? 条件满足时的值 : 条件不满足时的值`

| 案例 | 说明 |
|------|------|
| `A1>1000 ? "正常值" : "低值"` | A1 大于 1000 返回 "正常值"，否则返回 "低值" |
| `A1>1000 and A1<20000 ? "正常值" : "修正值："+(A1+100)` | 多条件判断，不满足时返回拼接字符串 |

#### 2.2 if 判断

**语法**：`if(条件){返回值} else if(条件){返回值} else{返回值}`

| 案例 | 说明 |
|------|------|
| `if(A1>1000){return "正常值"}` | 满足条件返回 "正常值"，否则无输出 |
| `if(A1>1000){return "正常值"}else{"低值"}` | 满足返回 "正常值"，否则返回 "低值"；return 和分号均可选 |
| `if(A1>1000 and A1<20000){return "正常值:"+A1}else if(A1>20000 and A1<40000){return "超高值"}else{"低值"}` | 多重条件判断 |

#### 3. case 判断

**语法**：`case{条件1 返回值1, 条件2 返回值2, ...}`

| 案例 | 说明 |
|------|------|
| `case{A1==100 return "正常值",A1>100 and A1<1000 return '偏高'}` | 两个条件分别返回不同值 |
| `case{A1==100 return "正常值",A1>100 and A1<1000 '偏高'}` | return 关键字可选 |

### (三) 单元格引用

#### 1. 直接引用

在表达式中直接写单元格名称即可引用，引用的目标单元格是相对当前单元格计算的。

| 引用方式 | 说明 |
|---------|------|
| `A1` | 引用 A1 单元格，遵循同行/同列/共同父格取值原则 |

**取值原则**：
1. 目标格与当前格位于同一行或列 → 直接取对应行/列上的目标格值
2. 不在同一行或列但有共同父格 → 取共同上父格与共同左父格交集部分的目标格值
3. 无共同父格 → 取迭代后所有目标格值
4. 取到多个值时，输出以逗号分隔

#### 2. 单元格坐标引用

**语法**：`单元格名称[L父格名:序号,L父格名:序号,...;T父格名:序号,T父格名:序号,...]{条件}`

- L 表示左父格，T 表示上父格
- 序号为正值表示向下/右位移，负值表示向上/左位移
- 只有左父格时直接写 L 部分；只有上父格时前面加 `;` 号
- 大括号中为条件过滤，可选

| 案例 | 说明 |
|------|------|
| `C1[A1:2,B1:1]` | 找 A1 展开后第2格下 B1 展开后第1格对应的 C1 |
| `C2[A1:2,B1:2;C1:3]` | 左父格和上父格交叉定位 C2 |
| `C2[A1:2,B2:2]{C2>1000}` | 坐标定位后再按条件过滤 |
| `C2[A1:2,B2:2]{C2>1000 and C2<10000}` | 多条件过滤 |

#### 3. 引用所有单元格

| 引用方式 | 说明 |
|---------|------|
| `A1[]` | 引用所有 A1 单元格，不受当前格位置限制 |
| `A1[]{@>1000 and @<10000}` | 引用所有 A1，且值在 1000~10000 之间；`@` 表示当前循环对象 |

#### 4. 取当前单元格值

| 引用方式 | 说明 |
|---------|------|
| `#` | 取当前单元格的值 |
| `#.id` | 取当前单元格绑定数据对象的 id 属性值 |
| `#.属性名` | 取当前单元格绑定数据对象的指定属性值；非数据集类型返回 null；多个值时取第一个 |

#### 3.5 取单元格展开序号

| 引用方式 | 说明 |
|---------|------|
| `&A2` | 取 A2 单元格展开后的序号；当前格必须是 A2 的子格或间接子格 |

**序号编排规则**：如果当前格与目标格有共同父格，以共同父格下目标格数量编排序号。

#### 6. 取目标格相对单元格值

| 引用方式 | 说明 |
|---------|------|
| `$B2` | 取相对于目标单元格的 B2 值，多用于条件比较 |

**典型场景**：`C2[A2:-1]{B2==$B2}`，其中 B2 是当前行的 B2 值，$B2 是坐标定位后目标 C2 对应的 B2 值。

### 4、数据集表达式

数据集表达式用于在单元格表达式中直接绑定数据集字段，语法结构为：

**`数据集名称.聚合方式(字段名[, 条件[, 排序方式]])`**

聚合方式枚举值（AggregateType）：

| 聚合方式 | 说明 | 适用数据源 | 语法 |
|---------|------|-----------|------|
| select | 罗列数据 | jdbc / buildin / spring | `datasetName.select(propertyName,filter,order)` |
| group | 分组罗列数据 | jdbc / buildin / spring | `datasetName.group(propertyName,filter,order)` |
| customgroup | 自定义分组 | jdbc / buildin / spring | 需配合自定义分组配置 |
| regroup | 重新分组 | jdbc / buildin / spring | — |
| reselect | 重新罗列 | jdbc / buildin / spring | — |
| sum | 累加 | jdbc / buildin / spring | `datasetName.sum(propertyName,filter)` |
| avg | 求平均值 | jdbc / buildin / spring | `datasetName.avg(propertyName,filter)` |
| max | 取最大值 | jdbc / buildin / spring | `datasetName.max(propertyName,filter)` |
| min | 取最小值 | jdbc / buildin / spring | `datasetName.min(propertyName,filter)` |
| count | 统计数量 | jdbc / buildin / spring | `datasetName.count(filter)` |

#### 4.1 select（罗列数据）

| 案例 | 说明 |
|------|------|
| `ds1.select(username)` | 取 ds1 中所有 username |
| `ds1.select(username,age>18)` | 取 age>18 的 username |
| `ds1.select(username,age>18,desc)` | 取 age>18 的 username 并倒排序 |
| `ds1.select(username,age>18 and age<60,asc)` | 多条件 + 正排序 |

#### 2. group（分组罗列数据）

| 案例 | 说明 |
|------|------|
| `ds1.group(degree)` | 对 degree 字段分组 |
| `ds1.group(degree,age>18)` | 对 age>18 的 degree 分组 |
| `ds1.group(degree,age>18,asc)` | 分组后正排序 |

#### 3. sum（累加数据）

| 案例 | 说明 |
|------|------|
| `ds1.sum(salary)` | 对 salary 累加 |
| `ds1.sum(salary,age>30)` | 对 age>30 的 salary 累加 |

#### 4. count（统计数量）

| 案例 | 说明 |
|------|------|
| `ds1.count()` | 统计 ds1 对象数量 |
| `ds1.count(age>30)` | 统计 age>30 的对象数量 |

#### 5. max（取最大值）

| 案例 | 说明 |
|------|------|
| `ds1.max(salary)` | 取 salary 最大值 |
| `ds1.max(salary,age>30)` | 取 age>30 的 salary 最大值 |

#### 6. min（取最小值）

| 案例 | 说明 |
|------|------|
| `ds1.min(salary)` | 取 salary 最小值 |
| `ds1.min(salary,age>30)` | 取 age>30 的 salary 最小值 |

#### 7. avg（取平均值）

| 案例 | 说明 |
|------|------|
| `ds1.avg(salary)` | 取 salary 平均值 |
| `ds1.avg(salary,age>30)` | 取 age>30 的 salary 平均值 |

### 5、典型表达式案例

#### 5.1 环比计算

```
C2 - C2[A2:-1]
```
取当前行 C2 值减去上一行 A2 对应的 C2 值。`A2:-1` 表示坐标上移一格。

#### 2. 同比计算

```
C2 - C2[A2:-1]{B2==$B2}
```
取当前行 C2 值减去上一年同月的 C2 值。`B2==$B2` 确保月份一致。

#### 5.3 逐层累加

```
if(&A2==1){return C2}else{C2+D2[A2:-1]}
```
第一行取 C2 值，后续行取当前 C2 加上一行 D2 值，实现逐行累加。

#### 4. 条件显示

```
if(&A2==1){return ""}else{C2-C2[A2:-1]{B2==$B2}}
```
第一行显示空字符串，其余行显示同比值。

## 三、表达式通用约束

| 约束编号 | 约束说明 |
|---------|---------|
| E-01 | 单元格引用始终相对当前单元格计算，遵循同行/同列/共同父格取值原则 |
| E-02 | 取到多个值时以逗号分隔输出；如需单一值，应使用聚合函数或坐标定位 |
| E-03 | 数据集表达式中聚合方式必须与 AggregateType 枚举值一致：group / customgroup / regroup / select / reselect / sum / avg / max / min / count |
| E-04 | 数据集表达式中排序方式可选值为 `asc`（正序）和 `desc`（倒序） |
| E-05 | sum / avg / max / min / count 聚合方式无排序参数（结果为单一值） |
| E-06 | 条件中 `and` / `or` 连接多个条件，`==` 判断相等，`$单元格名` 取目标格相对值 |
| E-07 | `&单元格名` 取展开序号，当前格必须是目标格的子格或间接子格 |
| E-08 | `#` 取当前单元格值，`#.属性名` 取绑定对象属性；非数据集类型返回 null |
| E-09 | `A1[]` 引用所有 A1 单元格不受位置限制，`@` 在条件中代表当前循环对象 |
| E-10 | if/case 中 `return` 关键字和行尾分号 `;` 均为可选 |
