# 函数说明

## 一、概念说明

函数是 Luck-Report 内置的可调用计算单元，可在单元格表达式、条件属性等位置使用。函数语法格式为 `函数名(表达式, 表达式, ...)`，参数可以是单元格引用、数据集表达式、字面量或其他函数的返回值。

## 二、函数分类

| 分类 | 函数数量 | 说明 |
|------|---------|------|
| 常用函数 | 14 | 统计、排序、取参、格式化等 |
| 日期函数 | 5 | 获取当前日期、年、月、日、星期 |
| 数学函数 | 18 | 绝对值、四舍五入、三角函数等 |
| 字符串函数 | 8 | 查找、截取、替换、大小写转换等 |
| 分页函数 | 8 | 当前页统计、页码输出 |

## 三、常用函数速查

| 函数名 | 说明 | 案例 |
|--------|------|------|
| count | 统计数量 | `count(C1)` |
| sum | 累加 | `sum(C1)` |
| avg | 求平均值 | `avg(C1)` |
| max | 取最大值 | `max(C1)` |
| min | 取最小值 | `min(C1)` |
| row | 取当前行号 | `row()` |
| column | 取当前列号 | `column()` |
| order | 排序 | `order(C1,false)` 倒序 |
| param | 获取参数 | `param("deptId")` |
| formatdate | 格式化日期 | `formatdate(C1,"yyyyMMdd")` |
| formatnumber | 格式化数字 | `formatnumber(C1,"#,###.00")` |

## 四、分页函数

分页函数在分页预览时计算，多用于重复表头/表尾行。

| 函数名 | 说明 |
|--------|------|
| pcount | 统计当前页数量 |
| psum | 累加当前页值 |
| page | 输出当前页码 |
| pages | 输出总页数（仅页眉页脚可用） |

## 五、数据约束

数据约束由 data-schemas.ts 自动校验。主要约束：
- 函数名大小写不敏感
- sum/avg/max/min 要求参数值为数字类型
- 分页函数只在分页预览时生效
- pages 函数仅能在页眉页脚中使用
