# 表达式说明

## 一、概念说明

表达式是 Luck-Report 中用于动态计算值的语法结构，可在单元格值（类型为 expression）、条件属性、图片来源、二维码数据源等位置编写。表达式由基本数据类型、运算符、条件判断、单元格引用、数据集表达式和函数调用组合而成。

## 二、表达式核心能力

| 分类 | 说明                       |
|------|--------------------------|
| 基本数据类型 | 数字、字符串、布尔值               |
| 算术运算符 | +、-、*、/、%                |
| 条件判断 | 三元表达式、if 判断、case 判断      |
| 单元格引用 | 直接引用、坐标引用、引用所有、取当前值      |
| 数据集表达式 | 数据集名称.聚合方式(字段名[条件,排序方式]) |
| 函数调用 | 内置函数，详见 FUNCTION 函数说明文档  |

## 三、单元格引用语法

| 引用方式 | 说明 |
|---------|------|
| `A1` | 直接引用 A1 单元格 |
| `A1[]` | 引用所有 A1 单元格 |
| `C1[A1:2,B1:1]` | 坐标引用，定位 A1 展开后第2格下 B1 展开后第1格对应的 C1 |
| `#` | 取当前单元格的值 |
| `#.属性名` | 取当前单元格绑定数据对象的属性值 |
| `&A2` | 取 A2 单元格展开后的序号 |
| `$B2` | 取目标格相对单元格的 B2 值 |

## 四、表达式语法

### 1. 基本组成

| 元素 | 说明 | 示例 |
|------|------|------|
| 数据类型 | 数字 / 字符串（单/双引号包裹） / 布尔（true、false） | `1`、`"Luck"`、`true` |
| 运算符 | `+ - * / %`，`+` 也用于连接字符串 | `"值："+331`、`21+31` |
| 条件运算 | `and` / `or` / `>` `<` `>=` `<=` `==` `!=` | `A1>1000 and A1<20000` |
| 函数调用 | 内置函数，可嵌套 | `count(A1[])`、`sum(ds1.salary)` |

### 2. 多段表达式

用 `;` 分成多段，**表达式执行完最后一行代码的结果**会作为整个表达式的返回值（if中只有满足条件的分支才会执行到最后）；`return` 关键字在表达式中**不生效**，但写在 `if` / `case` 分支中可提高可读性。

### 3. 条件判断

| 形式 | 语法 | 示例 |
|------|------|------|
| 三元 | `条件 ? 真值 : 假值` | `A1>1000 ? "正常" : "低值"` |
| if | `if(条件){...}else if(...){...}else{...}` | `if(A1>1000){return "高"}else{"低"}` |
| case | `case{条件1 return 值1, 条件2 return 值2}` | `case{A1==100 return "正常",A1>100 return "高"}` |

`return` 在 `if` / `case` 分支中可选。

## 五、数据集表达式语法

**格式**：`数据集名称.聚合方式(字段名[, 条件[, 排序方式]])`

| 聚合方式 | 说明 |
|---------|------|
| select | 罗列数据 |
| group | 分组罗列数据 |
| sum | 累加 |
| avg | 求平均值 |
| max | 取最大值 |
| min | 取最小值 |
| count | 统计数量 |

条件中可使用 `@` 表示当前循环对象；排序方式可选 `asc` / `desc`。

## 六、典型表达式案例

| 案例 | 说明 |
|------|------|
| `C2 - C2[A2:-1]` | 环比计算，当前行减上一行 |
| `C2 - C2[A2:-1]{B2==$B2}` | 同比计算，确保月份一致 |
| `if(&A2==1){ var a = C2; var b = D2; return a + b }else{C2+D2[A2:-1]}` | 逐层累加 |
| `ds1.sum(salary,age>30)` | 条件聚合 |

## 七、数据约束

数据约束由 data-schemas.ts 自动校验。主要约束：
- 单元格引用相对当前单元格计算
- 取到多个值时以逗号分隔输出
- 聚合方式必须与 AggregateType 枚举值一致
- 排序方式可选值为 asc 或 desc
